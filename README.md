Trabalho apresentado à disciplina de Redes de Computadores do Departamento Acadêmico de Informática da Universidade Tecnológica Federal do Paraná.

### Descrição geral

Este projeto foca na implementação de uma aplicação que opera sobre o protocolo TCP, utilizando programação com sockets e threads. O principal objetivo é o desenvolvimento de um servidor TCP multithread, que atenda múltiplos clientes simultaneamente e ofereça transferência de arquivos com verificação de integridade (SHA) e um serviço de chat, consolidando o conhecimento sobre o funcionamento orientado a conexão do TCP e contrastando-o com o UDP. 

### Objetivo do Projeto

Desenvolver uma aplicação cliente-servidor utilizando o protocolo TCP e programação de sockets. O servidor deve lidar com múltiplos clientes simultaneamente (multithreading) e oferecer transferência de arquivos com verificação de integridade (SHA) e um serviço de chat.
